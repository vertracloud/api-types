Add the Blob Storage contract (`blob.vertracloud.app`). Payloads: `APIBlobObject`, `APIBlobObjectList`, `APIBlobUpload`, `APIBlobUploadPart`, `APIBlobDownload`, `APIBlobLimits`, `APIBlobStats`, `APIBlobBatchResult`, `APIBlobDeleteResult`, `APIBlobUploadToken`, `APIBlobShare`, `APIBlobSharePublic`, `APIBlobRule`, `APIBlobRules`, `APIBlobS3Credentials`, `APIBlobCustomDomain`, and the `BlobVisibility`, `BlobContentDisposition`, `BlobUploadMode`, `BlobUploadStatus` and `BlobCustomDomainStatus` enums. REST types for objects (simple upload, list, get, update one or many, copy/move, delete one or many, temporary download link), direct and multipart uploads, shares (including the public share page routes), folder rules (`If-Match`), stats, upload tokens, S3 credentials and custom domains. New API key scopes `blob:read` and `blob:write`; new workspace permissions `blob:read` and `blob:manage` (not included in any seed role). New error codes: `BLOB_OBJECT_NOT_FOUND`, `BLOB_OBJECT_ALREADY_EXISTS`, `BLOB_UPLOAD_NOT_FOUND`, `BLOB_UPLOAD_EXPIRED`, `BLOB_UPLOAD_INCOMPLETE`, `BLOB_UPLOAD_LIMIT`, `BLOB_CHECKSUM_MISMATCH`, `BLOB_FILE_TOO_LARGE`, `STORAGE_QUOTA_EXCEEDED`, `BLOCKED_FILE_TYPE`, `BLOB_NAMESPACE_SUSPENDED`, `BLOB_UPLOAD_TOKEN_INVALID`, `BLOB_UPLOAD_TOKEN_EXHAUSTED`, `BLOB_UPLOAD_TOKEN_NOT_ALLOWED`, `BLOB_UPLOAD_TOKEN_CONSTRAINT`, `BLOB_SHARE_NOT_FOUND`, `BLOB_SHARE_EXHAUSTED`, `BLOB_SHARE_PASSWORD_INVALID`, `BLOB_RULES_CONFLICT`, `BLOB_RULE_LIMIT`, `BLOB_CUSTOM_DOMAIN_LIMIT`, `BLOB_CUSTOM_DOMAIN_TAKEN` and `BLOB_CUSTOM_DOMAIN_NOT_FOUND`.

Also: `RESTPostAPIBlobUploadTokenBody.overwrite` (an upload token never replaces an existing object unless it was created with `overwrite: true`); `APIBlobCustomDomain.verification` (the `TXT` record that proves ownership of a custom domain; the domain only turns `active` once it resolves); `checksum_sha256` is valid only for single-request and one-part direct uploads (a multipart upload refuses it). `APIBlobCustomDomain.web_content` and `PATCH /v1/domains/:domain_id` (`RESTPatchAPIBlobDomainBody`): a custom domain can serve `.html`, `.htm`, `.xhtml`, `.svg` and `.xml` in the browser, sandboxed; off by default.
